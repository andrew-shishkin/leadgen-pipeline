# Конвейер поиска ЛПР

Превращает список компаний в список людей с именами, должностями и рабочими
почтами. Заменяет собой связку колонок в Clay.

**Как это устроено:** откройте [docs/pipeline.html](docs/pipeline.html) в
браузере — там вся логика на схеме, без технических подробностей.

**Ловить компании по триггерам** (вакансии, реестры, тендеры) —
[docs/triggers.md](docs/triggers.md). Самый простой способ работает сразу,
ничего настраивать не надо.

---

## Установка

### 1. Node.js

Откройте Терминал и проверьте:

```bash
node --version
```

Номер версии 22 или выше — всё есть. «command not found» — скачайте установщик
с [nodejs.org](https://nodejs.org), кнопка LTS.

### 2. Скачать проект

Кнопка **Code → Download ZIP**. Распакуйте куда удобно, например в «Документы».

### 3. Установить

В Терминале перейдите в папку проекта:

```bash
npm install
cp .env.example .env
```

### 4. Вставить ключ

Откройте файл **`.env`** в текстовом редакторе. Не `.env.example` — это разные
файлы, и вставлять надо именно в `.env`.

Выберите, чья нейросеть будет считать:

**Если у вас подписка Claude** — оставьте `LLM_PROVIDER=anthropic` и вставьте
ключ с [console.anthropic.com](https://console.anthropic.com) → API Keys →
Create Key в строку `ANTHROPIC_API_KEY=`.

**Если у вас подписка ChatGPT или Codex** — поставьте `LLM_PROVIDER=openai`,
раскомментируйте строку `OPENAI_API_KEY=` и вставьте ключ с
[platform.openai.com](https://platform.openai.com). Заводить аккаунт Anthropic
не нужно.

В обоих случаях на счёте должны быть деньги — $20 хватит на несколько тысяч
компаний.

> **Ключ вставляется только в файл.** Не отправляйте его в переписку с Клодом
> или Codex: всё, что попадает в чат, остаётся в истории. Файл `.env` защищён
> от случайной публикации.

## Первый запуск

Прогоните демо-файл из 15 компаний:

```bash
node run.js import
node run.js fetch
node run.js qualify
node run.js export
```

Займёт пару минут и обойдётся центов в пятнадцать. После каждой команды
появится отчёт: сколько сайтов открылось, сколько компаний оказались мёртвыми,
сколько прошли отбор и сколько это стоило.

Результат — три файла в папке `out/`:

| Файл | Что внутри |
|---|---|
| `1-компании.csv` | все компании с отметкой, кто подошёл и почему |
| `2-ЛПР-с-почтами.csv` | люди с именными почтами, готово в рассылку |
| `3-общие-почты.csv` | компании, где пишем на `info@`, но знаем имя нужного человека |

## Свои данные

Положите файл в папку `data/` и укажите при импорте:

```bash
node run.js import --file data/мои-компании.csv
```

Колонки распознаются сами — программа понимает выгрузки из Контур Компас,
Datanewton, Sales Navigator и большинство других. Обязателен только **сайт**.
Всё остальное — ИНН, телефон, ФИО директора, почты — подхватится, если есть,
и пригодится дальше. ФИО директора сразу попадёт в список ЛПР: это готовый
контакт, за который не заплачено ничего.

## Быстро или вдвое дешевле

Команда `node run.js qualify` спросит, как запускать:

**Обычный режим** — результат сразу, но компьютер должен быть включён всё
время работы.

**Пакетный режим** — ровно **вдвое дешевле**. Ответ приходит в течение часа
(предел — сутки). Считает сервер провайдера, а не ваш компьютер, поэтому
ноутбук можно закрыть и вообще выключить. Когда вернётесь:

```bash
node run.js collect
```

На больших списках выбирайте пакетный: на 5 000 компаний разница — примерно
$25 против $50.

## Настройка под себя

Меняются два текстовых файла, код трогать не нужно.

**`prompts/qualify.md`** — критерии отбора компаний. Сейчас там пример: ищем
производственные предприятия со станочным парком. Замените на свои.

Критерий должен быть проверяемым по сайту. Не «серьёзные компании», а «есть
собственное производство». Чем конкретнее — тем меньше спорных строк придётся
разбирать руками.

**`prompts/titles.md`** — какие должности вам нужны. Три списка: кого ищем,
что тоже засчитываем, и что похоже, но не подходит. Третий список не
пропускайте: без него на запрос «инженер» набежит толпа менеджеров по продажам
и системных администраторов.

## Команды

```
node run.js import   [--file data/файл.csv]     загрузить список, убрать дубли
node run.js fetch    [--only 20]                открыть сайты компаний
node run.js qualify  [--only 20]                отобрать подходящие
node run.js collect                             забрать пакетный прогон
node run.js report                              где мы сейчас и сколько потрачено
node run.js export                              выгрузить три таблицы
```

`--only 20` — обработать только первые 20 строк. Проверьте критерии на
небольшой выборке, прежде чем запускать весь список.

Все команды можно прерывать и запускать заново: программа продолжит с места
остановки и не заплатит второй раз за уже обработанное.

## Если что-то пошло не так

**«Не найден ключ доступа к нейросети»** — ключ не попал в `.env`. Самая частая
причина: вставили в `.env.example`. Это разные файлы.

**Много строк «под вопросом»** — обычно это сайты, которые не отдают текст без
браузера. Откройте `out/1-компании.csv`: если у таких пустая колонка «Что
производит», дело не в критериях.

**Мало компаний прошло отбор** — посмотрите в той же таблице колонки
«Обоснование» и «Цитаты с сайта». Там видно, за что зацепилась нейросеть.
Ошибается систематически — правьте `prompts/qualify.md`.

**Начать с нуля** — удалите папку `out/` и запустите импорт заново.

## Помощь Клода или Codex

В проекте лежат `CLAUDE.md` и `AGENTS.md` — агент читает их сам и понимает
устройство проекта. Откройте папку в Claude Code или Codex и попросите словами:

> Помоги настроить критерии отбора под мой бизнес — я продаю промышленные
> станки заводам

Агент нужен, чтобы **настроить** проект и объяснить результаты. Список
обрабатывает сам скрипт, и это не тратит лимиты вашей подписки.
